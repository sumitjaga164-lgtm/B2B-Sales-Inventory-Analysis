# B2B Sales & Inventory Data Analysis (Excel)

## Project Overview
This project demonstrates end-to-end data cleaning, automated inventory status tracking, and sales aggregation for B2B orders.

## Key Skills & Techniques Used
* **Data Cleaning & Standardization:** Formatted inconsistent customer names into proper case for accurate reporting.
* **Dynamic Formulas:** Automated total order value calculations and built conditional stock alerts (`READY TO SHIP` vs. `OUT OF STOCK`).
* **Pivot Tables & Charts:** Summarized total revenue by product category to deliver clear, actionable business insights.
